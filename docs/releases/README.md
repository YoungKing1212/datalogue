# 数语分阶段演示版本

本目录记录数语（智能问数）的四个累计式演示版本。版本按照智能问数能力逐步开放，而不是按照前端、后端或提交时间拆分：

| 版本 | 演示主题 | 本期核心增量 |
| --- | --- | --- |
| [1.0.0](1.0.0.md) | 自然语言单表查询 | 明细、筛选、排序和单表基础统计 |
| [1.1.0](1.1.0.md) | 简单多表关联查询 | 基于明确关系的两表或少量多表查询 |
| [1.2.0](1.2.0.md) | 指标与维度语义查询 | 按业务指标、分析维度完成聚合分析 |
| [1.3.0](1.3.0.md) | 子智能体显性协作 | 展示主智能体与 BI 子智能体的安全协作过程 |

## 版本原则

- 四个版本是累计升级关系，后一版本包含前一版本已经开放的能力。
- 底层保持同一条稳定查询主链，通过演示能力配置限制允许执行的查询范围，避免维护四套相互分叉的查询实现。
- 前三个版本可以继续使用现有 Agent Team 运行链路，但不向演示观众暴露子智能体身份；`1.3.0` 才将协作过程作为产品能力展示。
- 每个版本必须在服务端执行边界校验，不能仅靠隐藏菜单、提示词或前端样式限制能力。
- 模型原始思考、SQL、Schema、QueryPlan、未清洗原始数据行和数据库原始错误不属于业务演示内容，所有版本均不得向普通用户暴露。

## 统一启动约定

各版本使用 `DATALOGUE_DEMO_CAPABILITY_LEVEL` 选择能力层级：

```env
# 1.0.0
DATALOGUE_DEMO_CAPABILITY_LEVEL=single_table

# 1.1.0
DATALOGUE_DEMO_CAPABILITY_LEVEL=multi_table

# 1.2.0
DATALOGUE_DEMO_CAPABILITY_LEVEL=semantic_metrics

# 1.3.0
DATALOGUE_DEMO_CAPABILITY_LEVEL=agent_team
```

四个版本统一保持以下未完成能力关闭：

```env
ENABLE_REPORT_WORKER=false
ENABLE_REPORT_UI=false
ENABLE_RAW_THINKING=false
ENABLE_FULL_OBSERVABILITY=false
```

实际环境变量名称以对应 Tag 中的实现和示例配置为准。启动前应完成数据库迁移，并按项目现有启动说明运行 API 与 Web 服务。

## 不纳入本轮成果的能力

以下内容尚未形成可稳定验收的完整能力，不写入四期已完成成果，也不作为现场承诺：

- 智能报告和 Report Worker 稳定自动触发；
- 完整链路可观测平台、生产告警和监控；
- 生产级部署、容灾和运维闭环；
- 图表化分析报告；
- 完整角色权限与数据治理闭环。

`Report Worker` 在四个演示版本中默认禁用。相关代码或工程基础即使存在，也只代表后续建设基础，不代表能力已经完成。

## Tag 命名与发布

版本 Tag 使用语义化版本号：`1.0.0`、`1.1.0`、`1.2.0`、`1.3.0`。发布前应逐期完成对应文档中的验收项，再创建带说明的 Tag 并推送到远程仓库。
