# 数语 1.0.0：自然语言单表查询

## 版本定位

`1.0.0` 建立智能问数的最小可用闭环：用户用自然语言描述查询需求，系统在一张业务表内完成字段选择、条件筛选、排序、数量限制和基础统计，并返回可读答案与结果表格。

本期对外只表达“自然语言单表查询”，不介绍内部 Agent Team、Leader 或 BI Worker。底层即使复用当前稳定主链，对用户也统一呈现为“正在查询数据”。

## 已开放能力

- 单表明细查询；
- 等值、范围和时间条件筛选；
- 单表字段选择、排序和结果数量限制；
- 单表记录数等基础统计；
- 自然语言答案和结果表格；
- 基础连续追问，但追问仍需落在同一单表能力范围内。

## 能力限制

- 每次查询最多涉及一张表；
- 不允许 Join、多表支持实体或跨表字段；
- 不开放指标定义、维度分组和复杂聚合；
- 不展示子智能体身份、工具调用过程和 Repair 过程；
- 超出能力范围的问题应明确提示当前版本暂不支持，不能静默降级为错误结果。

## 推荐演示问题

1. “查询杨凯 2024 年的工作日志。”
2. “只看状态为已完成的记录。”
3. “按创建时间倒序，返回最近 20 条。”
4. “2024 年一共有多少条工作日志？”

演示数据应选择字段含义清晰、结果稳定的一张表，避免问题隐含跨表关系或业务指标口径。

## 启动配置

```env
DATALOGUE_DEMO_CAPABILITY_LEVEL=single_table
ENABLE_REPORT_WORKER=false
ENABLE_REPORT_UI=false
ENABLE_RAW_THINKING=false
ENABLE_FULL_OBSERVABILITY=false
```

演示环境只发布单表数据集，或确保当前账号只能选择单表演示数据集。服务端必须在查询计划执行前拒绝 Join、Supporting Entities、Metrics 和 Group By。

## 验收标准

- 四类推荐问题均能稳定返回正确答案和结果表；
- 单表筛选、排序、限制数量和计数结果与数据库核对一致；
- 输入明显的跨表问题时，系统不执行越权查询并给出可理解提示；
- 页面和事件流不出现 Leader、BI Worker、SQL、Schema、QueryPlan 或 Raw Thinking；
- Report Worker 不触发，也不存在智能报告入口。

## 下一期预告

`1.1.0` 将在单表能力基础上开放基于明确数据关系的简单多表关联查询，解决人员、部门、项目等业务实体需要组合查询的问题。
