# 运行时健康检查

> 用途：面向本地开发、交接部署和 OpenViking 接入前检查。本文是 P1 运维产品化规格，不新增 runtime 行为；现有接口以源码和 OpenAPI 为准。

## 检查原则

- 先确认唯一主链：`POST /api/agent-team/tasks/stream → AgentScope Agent Team → BI Worker Tools`。
- 健康检查只输出状态、计数、refs 和安全摘要；SQL、schema、raw rows、原始数据库报错与 private diagnosis 只允许留在后端 debug/trace。
- 发现问题时优先定位控制面、执行面、事件投影或前端构建，不把旧 session / 旧 prompt / 旧 uvicorn 进程误判为业务失败。

## 必查项

| 检查项 | 成功标准 | 失败定位建议 |
|---|---|---|
| AgentScope Service | `/api/agentscope-control/status` 返回 enabled/ready，`/agentscope` 子应用已挂载 | 检查 `AGENTSCOPE_SERVICE_ENABLED`、FastAPI lifespan、子应用 mount 路径和 307/404 |
| Redis | AgentScope storage/message bus 可连通，会话锁、回放日志、收件箱可用 | 检查 Redis 容器、host/port、连接池、跨进程 message bus 配置 |
| Credential | 默认模型 credential / ModelCard 可读取，聊天请求能拿到 `model_credential_id` | 检查 AgentScope credential 表单、设置页、控制面代理和过期配置 |
| Leader Agent | Leader 规格已注册，能通过 AgentScope Service 创建或复用 | 检查 `registry.py`、prompt 模板格式化、官方 AgentCreate/TeamSay 工具 |
| Session stream | AgentScope session SSE 可订阅并能投影到 DatalogueEventEnvelope | 检查 session id、thread id、stream 超时、pending tool call 是否被误判完成 |
| BI Tool | 候选筛选、上下文准备、schema 证据、QueryPlan 执行、repair 工具已注册 | 检查 `tools.py`、worker prompt 工具列表、QueryPlan 契约和 stop_retry |
| Artifact API | `artifact_ref` 可读取，结果摘要与详情分层可用 | 检查 artifact writer、Workbench 线程视图、数据库事务和 ref 映射 |
| Frontend version | 前端是当前构建，assistant-ui 可见层、结果卡、ThreadList 与 URL 同步正常 | 检查 dev server 端口、旧构建缓存、浏览器 session 和前端 adapter 测试 |

## 最小验证顺序

1. `GET /api/agentscope-control/status`：确认 AgentScope Service、Redis 和配置基础可用。
2. 设置页读取 credential：确认模型配置不是旧本地 LLM 表残留。
3. 发起 `POST /api/agent-team/tasks/stream`：确认只走 Agent Team 主入口。
4. 观察事件：用户可见 SSE 只出现业务摘要、结果卡、artifact refs，不出现 SQL/schema/raw rows。
5. 打开 Workbench / artifact：确认 checkpoint、retry action 和 artifact 详情可追踪。
6. 检查后端日志：debug 信息分为 Leader / Worker / Tool / DB，不把 private diagnosis 投到前端。

## 常见误判

- 页面像旧版本：先查前端端口、旧 dev server、浏览器缓存和当前 worktree。
- AgentScope 任务提前结束：先查 `message.completed` 是否仍带 pending tool call。
- BI Worker 很慢：先查 QueryPlan 契约和 schema evidence，不要直接绕过 Leader。
- 空结果或失败：先查 repair 链路是否产生 safe diagnosis、checkpoint/ref 和用户确认卡。
