# 文档素材说明

本目录只放当前文档可继续引用的图片、截图和素材。

仓库不再保留顶层 `assets/`。当前文档资源统一放在这里，已失效的截图、原型和设计源文件统一放入 `docs/archive/`。

当前规则：

- 当前架构正文放在 `docs/architecture/`，引用的图片放在 `docs/assets/diagrams/`。
- 旧 QueryGraph / LeadAgent 全链路图已迁移到 `docs/archive/2026-07-03-legacy-assets/`，只作为历史素材。
- `screenshots/` 下的用户手册截图是产品界面素材，不代表后端 Agent / runtime 架构。
- `diagrams/architecture/` 保存当前架构和工具链路文档引用的图。
- 新增素材时，如果表达的是历史方案，必须直接放入 `docs/archive/` 或在同目录 README 标明历史状态。
