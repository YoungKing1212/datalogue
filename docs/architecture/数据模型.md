# 核心数据模型

> 基于 `app/models/` 当前实际代码

## 一、问数与 Agent 执行

### AgentTeamTask（`agent_team_task`）
| 字段 | 类型 | 说明 |
|------|------|------|
| `task_id` | UUID PK | 任务唯一 ID |
| `trace_id` | string | 追踪链 ID |
| `thread_id` | string | AgentScope session ID |
| `message_id` | string | 关联消息 ID |
| `selected_agent` | string | 选定的 Agent 类型 |
| `question` | text | 用户原始问题 |
| `task_type` | string | bi_query / report / python_analysis |
| `dataset_id` | int | 选定的数据集 ID |
| `status` | string | created / running / completed / failed |
| `final_payload_json` | JSON | 最终回答摘要 |
| `artifact_refs_json` | JSON | 产物引用列表 |
| `checkpoint_refs_json` | JSON | 检查点引用列表 |
| `agent_scope_session_id` | string | AgentScope 侧 session ID |

### Conversation（`conversation`）
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int PK | |
| `thread_id` | string | AgentScope thread ID |
| `title` | string | 会话标题 |
| `status` | string | active / archived |

### Message（`message`）
| 字段 | 类型 | 说明 |
|------|------|------|
| `message_id` | UUID PK | |
| `thread_id` | string | 所属会话 |
| `role` | string | user / assistant |
| `content_summary` | text | 内容摘要 |
| `payload` | JSON | 完整负载 |
| `status` | string | running / completed / failed |

## 二、数据集治理

### SemanticDataset（`semantic_dataset`）
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int PK | |
| `name` | string | 数据集名称 |
| `datasource_id` | FK → datasource | 绑定的数据源 |
| `tables_json` | JSON | 选中的表信息 |
| `description` | text | 业务描述 |
| `prompt_instructions` | text | LLM 约束 |
| `query_constraints` | JSON | 查询约束（默认 LIMIT 100 + 近30天） |
| `status` | string | draft / active |

### SemanticMetric（`semantic_metric`）
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int PK | |
| `dataset_id` | FK | 所属数据集 |
| `name` / `display_name` | string | 名称/显示名 |
| `expr` | text | SQL 表达式 |
| `table_name` | string | 源表 |
| `time_field` | string | 时间字段 |
| `granularity` | string | 粒度 |
| `filter_sql` | text | 过滤条件 |
| `synonyms` | JSON | 同义词 |

### SemanticDimension（`semantic_dimension`）
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int PK | |
| `dataset_id` | FK | |
| `name` / `display_name` | string | 名称/显示名 |
| `column_name` | string | 对应列名 |
| `table_name` | string | 源表 |
| `hierarchy` | JSON | 层级结构 |
| `enum_values` | JSON | 枚举值 |
| `synonyms` | JSON | 同义词 |

### BusinessTerm（`business_term`）
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int PK | |
| `dataset_id` | FK | |
| `name` / `display_name` | string | 名称 |
| `term_type` | string | metric_concept / dimension_enum / business_object |
| `definition` | text | 定义 |
| `aliases` / `forbidden_aliases` | JSON | 别名/禁用名 |
| `status` | string | draft / active / deprecated |

### AnalysisBlueprint（`analysis_blueprint`）
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int PK | |
| `dataset_id` | FK | |
| `name` / `description` | string | 名称/描述 |
| `trigger_keywords` / `trigger_examples` | JSON | 触发条件 |
| `parameters` | JSON | 参数定义 |
| `implementation_type` | string | stored_procedure / ai_generated |
| `call_template` | text | 调用模板 |
| `output_schema` | JSON | 输出格式 |
| `raw_sql` | text | 原始 SQL |
| `steps` | JSON | 执行步骤 |
| `status` | string | draft / active / deprecated |

### DatasetSubAgentManifest（`dataset_subagent_manifest`）
| 字段 | 类型 | 说明 |
|------|------|------|
| `dataset_id` | FK PK | |
| `manifest_version` | string PK | 版本号 |
| `manifest_json` | JSONB | Manifest 内容 |
| `is_current` | bool | 是否为当前版本 |
| `review_status` | string | draft / reviewed |

## 三、数据源管理

### Datasource（`datasource`）
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int PK | |
| `name` | string | 数据源名称 |
| `db_type` | string | postgresql / mysql / oracle / ... |
| `host` / `port` / `database` / `username` | string/int | 连接参数 |
| `status` | string | active / error |

### SourceTable（`source_table`）
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int PK | |
| `datasource_id` | FK | |
| `schema_name` / `table_name` | string | schema/表名 |
| `table_comment` | text | 表注释 |
| `ai_description` / `user_description` | text | 描述 |
| `effective_desc` | text | 生效中的描述 |
| `desc_source` | string | ai / user / manual |
| `row_count_approx` | int | 行数 |
| `status` | string | active |

### SourceColumn（`source_column`）
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int PK | |
| `table_id` | FK | |
| `column_name` | string | 列名 |
| `data_type` | string | 数据类型 |
| `column_comment` | text | 列注释 |
| `ai_description` / `user_description` | text | AI/人工描述 |
| `ai_semantic_role` | string | AI 标注角色 |
| `effective_desc` | text | 生效描述 |
| `review_status` | string | pending_review / confirmed / ignored |
| `sample_values` | JSON | 采样值 |
