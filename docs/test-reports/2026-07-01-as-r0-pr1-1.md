# AS-R0 PR1.1 Test Report: Runtime adapter 接管入口

## Scope

- 正式计划项：PR1.1 Runtime adapter 接管入口。
- 目标：新增 AgentScope runtime adapter，使 `/chat/stream` 在 feature flag 开启时作为 HTTP/SSE 兼容壳委托 `DatalogueAgenticShell.run_turn()`。
- 非目标：不替换 DatasetAgent 主链，不提前实现 PR1.3 tool-call runtime，不改变 final payload / artifact refs / mirror 写入兼容行为。

## Implementation Summary

- 新增配置 `AS_R0_AGENTIC_RUNTIME_ENABLED`，默认关闭。
- `DatalogueAgenticShell.run_turn()` 先执行 `prepare_turn()`，再委托 legacy stream delegate，保持现有 SSE 输出兼容。
- `/chat/stream` 单轮和多轮入口改为调用 `_stream_chat_singleturn_via_agentic_runtime()`；flag 关闭时直接回退 `_stream_chat_singleturn()`。
- Chat payload 只向 Shell 投影 `conversation_id`、`dataset_id`、`thread_id`、`session_id`、`checkpoint_ref` 等业务句柄，不传 SQL、schema、raw rows 或内部执行态 payload。

## Acceptance Mapping

- `/chat/stream` 兼容壳存在，且在 flag 开启时会委托 `DatalogueAgenticShell.run_turn()`。
- flag 默认关闭，legacy `_stream_chat_singleturn` 可回退。
- Shell context projection 只包含业务句柄，不含禁止进入 Agent context 的 SQL/schema/raw rows/query_plan/RepairPatch/blueprint body。
- PR1.1 不提前替换主链执行器；DatasetAgent tool-call runtime 仍按正式计划留给 PR1.3。

## Residual Risk

- 当前只是 runtime ownership 的入口适配，真实 BI LeadAgent capability routing、DatasetAgent tool-call runtime、checkpoint/retry writer 迁移和双路径灰度仍分别归 PR1.2 - PR1.5。
