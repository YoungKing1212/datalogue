# AS-R0 P2.2 Test Report: legacy adapter / ask_bi compatibility 收敛

## Scope

- 正式计划项：P2.2。
- 目标：把 `AgentScopeShellAdapter + BIWorkbenchTool(ask_bi)` 标记为 legacy compatibility，避免旧外壳继续被理解为 BI 主链 runtime ownership。
- 非目标：不启用 ReportAgent/PythonAgent/AuditAgent，不改变 `ask_bi` 外部响应形状，不把 `ask_bi` 加回 AS-R0 atomic tool whitelist。

## Implementation Summary

- `AgentScopeShellAdapter` 新增 `compatibility_contract()`，声明：
  - `compatibility_mode=legacy_compatibility`
  - `runtime_owner=datalogue_agentic_shell`
  - `owns_business_runtime=false`
  - `legacy_tool_name=ask_bi`
- `BIWorkbenchTool` 新增 `compatibility_contract()`，声明 `ask_bi` 只保留为旧兼容工具。
- `BI_SOUL.md` 与 Hermes SOUL 同步块更新为 AS-R0/P2 口径：主 Runtime ownership 属于 Datalogue Agentic Shell，legacy `ask_bi` 不再作为新主链工具。
- `render_agentscope_shell_policy()` 改为输出 legacy compatibility policy，而不是“allowed_tools: ask_bi”新主链口径。

## TDD Evidence
