# AS-R0 P2.1 Test Report: `/chat/stream` transport adapter 收缩

## Scope

- 正式计划项：P2.1。
- 目标：把 `_stream_chat` 收缩为 transport adapter，业务 turn lifecycle 从 `chat.py` 迁走。
- 非目标：不改 DatasetAgent 主链，不改 `/chat/stream` SSE payload，不处理 P2.2 legacy `AgentScopeShellAdapter + ask_bi` compatibility。

## Implementation Summary

- 新增 `app/services/agentic_chat_runtime.py`。
- 新增 `DatalogueChatStreamRuntime` 和 `DatalogueChatStreamRuntimeHooks`。
- `_stream_chat()` 现在只负责读取 settings、装配 hooks、创建 runtime 并转发 runtime stream 事件。
- 单轮 AgentScope bridge 收口、多轮 lock/retry/checkpoint/pending clarification/final persist lifecycle 已迁入 runtime service。
- 既有底层业务 helper 仍通过 hooks 复用，避免 P2.1 扩大成主链重写。

## TDD Evidence

1. RED：新增 `test_chat_stream_transport_adapter_delegates_to_runtime_service` 后失败，原因是 `app.api.chat` 还没有 `DatalogueChatStreamRuntime` 接入点。
2. GREEN：新增 runtime service 并将 `_stream_chat` 改为薄 adapter 后，该测试通过。
3. Regression fix：chat bridge 回归发现多轮 persist failure 场景重复 yield final；修复为 final 分支只输出补齐 thread_id 后的 final，并保留 retry final 前置事件顺序。

## Acceptance Mapping

- `_stream_chat` is now a transport adapter that delegates to `DatalogueChatStreamRuntime.stream()`。
- Existing `/chat/stream` final payload remains compatible。
- Existing AgentScope mirror completed/failed/interrupted handling remains covered。

## Residual Risk

- P2.1 deliberately keeps legacy helper functions in `chat.py` as hooks. P2.2 should mark or convert `AgentScopeShellAdapter + BIWorkbenchTool(ask_bi)` as legacy compatibility without expanding this adapter refactor.
