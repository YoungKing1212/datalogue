# AS-R0 PR1.4 Test Report: checkpoint/retry 迁移

## Scope

- 正式计划项：PR1.4 checkpoint/retry 迁移。
- 目标：Workbench retry 调 Shell action；Shell writer 写 `retry.started`、`retry.checkpoint_restored`、`dataset.query.completed`、`answer.completed` 等事件，并继续满足 provider-neutral observability contract。
- 非目标：不改变 retry API 请求形状，不改变默认 `/chat/stream` 输出，不做 PR1.5 双路径 parity 切换。

## Implementation Summary

- 新增 `AgentScopeMirrorShellWriter`。
- Workbench retry request 改为通过 `DatalogueAgenticShell.record_action()` 写入 `workbench.retry_requested`。
- Chat SSE event projection 改为通过 `DatalogueAgenticShell.record_event()` 和 Shell writer 写入 AgentScope mirror。
- Writer 底层复用既有 `record_stream_event()` / `record_agentscope_event()`，避免重写 Workbench projection 语义。
- Shell 写回前继续清洗 payload，阻断 SQL、schema、raw rows、query_plan 等内部执行载荷。

## TDD Evidence

1. RED：新增 PR1.4 测试后，Workbench retry module 没有 `DatalogueAgenticShell` 接入点，Chat SSE projection 没有调用 Shell `record_event()`。
2. GREEN：新增 writer 并接入 Workbench action / Chat SSE projection 后，PR1.4 定向测试通过。
