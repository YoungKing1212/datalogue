# AS-R0 P2.3 Test Report: future tools disabled/admin-gated contract

## Scope

- 正式计划项：P2.3。
- 目标：接入后续 tools 的受控契约：`repair_dsl`、`classify_query_failure`、`create_report_from_artifact`、`run_sandboxed_analysis_on_artifact`，默认 disabled 或 admin-gated。
- 非目标：不实现这些工具的执行逻辑，不注册到 Runtime executable tool registry，不启用 ReportAgent/PythonAgent/AuditAgent。

## Implementation Summary

- 新增 `AgenticDisabledToolSpec`。
- `AgenticToolPolicy` 新增 `disabled_tool_specs`。
- `DatalogueAgenticShell.prepare_turn()` 为 future tools 生成结构化 disabled/admin-gated contract。
- `AgentScopeRuntimeBoundaryContract` 透传 `disabled_tool_specs`，让 Runtime adapter 能审计 future tools 状态，但不会注册 callable。

## TDD Evidence
