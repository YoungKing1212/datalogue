# AS-R0 PR1.2 Test Report: BI LeadAgent 接入 Shell

## Scope

- 正式计划项：PR1.2 BI LeadAgent 接入 Shell。
- 目标：BI LeadAgent 只开放 `query_dataset` / `query_multiple_datasets` 能力路由；ReportAgent、PythonAgent、AuditAgent 返回 disabled action。
- 非目标：不执行 DatasetAgent tool-call runtime，不替换 compile/execute 主链，不启用 Report/Python/Audit 业务 Agent。

## Implementation Summary

- 新增 `AgenticShellAction` contract。
- 新增 `DatalogueAgenticShell.route_agent_action()` 和 `route_action_from_contract()`。
- BI task 默认路由到 `query_dataset`；只允许 `query_dataset` / `query_multiple_datasets`。
- BI 请求非白名单能力时返回 `capability_not_whitelisted` disabled action。
- Report/Python/Audit placeholder 返回 `agent_disabled_placeholder` disabled action。
- `AgentScopeRuntimeBoundaryContract` 新增 `lead_agent_action`，复用 Shell 的能力路由判断。

## TDD Evidence

1. RED：新增 Shell 能力路由测试后，定向运行失败，错误为 `DatalogueAgenticShell` 没有 `route_agent_action`。

3. RED：新增 Runtime boundary action 测试后，定向运行失败，错误为 `AgentScopeRuntimeBoundaryContract` 没有 `lead_agent_action`。
4. GREEN：Runtime boundary 加入 `lead_agent_action` 后，driver 定向测试通过。
