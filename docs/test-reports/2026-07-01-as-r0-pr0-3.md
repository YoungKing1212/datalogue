## 本次实现

- `BIAtomicToolProvider.compile_dsl_to_sql()`：
  - 接收 DatasetAgent 结构化 DSL / `QueryPlan`。
  - 内部调用现有 `compile_query_plan_to_sql()`。
  - 返回 `compiled_query_ref`、状态、dialect、execution_source 和执行守卫计数摘要。
  - 不返回 SQL、query_plan、schema、物理表字段或编译器内部载荷。

- `BIAtomicToolProvider.execute_compiled_query()`：
  - 只接受 `compiled_query_ref`。
  - 从 provider 私有句柄读取 SQL 并调用注入的 executor。
  - 查询结果写入 `ArtifactStore`。
  - Agent 可见响应只返回 `artifact_ref`、`row_count` 和 `column_count`。

- Shell / Runtime 边界：
  - `DatalogueAgenticShell` whitelist 开放六个 BI 原子工具。
  - `DatalogueAgentScopeRuntimeDriver` registry 同步注册六个工具。
  - Report/Python/Audit placeholder 仍 fail-closed，不注册工具。

## 安全断言

- compile response 不包含：
  - SQL 文本
  - 物理表名 / 字段名
  - `query_plan`
  - `sql_generation_context`
  - `sql_guard`

- execute response 不包含：
  - SQL 文本
  - raw rows
  - 物理表名
  - 查询结果行内容

- artifact 内部可保存查询结果；Agent 工具响应只暴露 artifact ref 和摘要计数。
