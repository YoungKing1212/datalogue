# AS-R0 PR1.3 Test Report: DatasetAgent tool-call runtime

## Scope

- 正式计划项：PR1.3 DatasetAgent tool-call runtime。
- 目标：用原子 tools 串起 `get_dataset_status -> list_candidate_assets -> DSL -> compile -> execute -> artifact summary`。
- 非目标：不启用 Report/Python/Audit；不把 `/chat/stream` 最终灰度切到新 runtime；不暴露 SQL/schema/raw rows/query_plan。

## Implementation Summary

- 新增 `DatasetAgentToolCallRuntime`。
- DSL 生成通过注入的 `dsl_generator` 完成，便于后续替换为真实 DatasetAgent DSL planner。
- Runtime 固定调用 `BIAtomicToolProvider` 的 atomic tools，不提供 `plan_bi_query` 黑盒。
- compile 成功后只使用 `compiled_query_ref` 私有句柄进入 execute。
- execute 写入 `ArtifactStore` 后只返回 artifact ref、row/column count 和 artifact summary。
- compile 失败时返回 blocked，并保证不调用 execute。

## Acceptance Mapping

- Tool-call sequence is exactly `get_dataset_status`, `list_candidate_assets`, `generate_dsl`, `compile_dsl_to_sql`, `execute_compiled_query`, `get_artifact_summary`.
- SQL stays inside compile/execute provider handle.
- Agent-visible runtime output does not contain SQL, schema body, raw rows, query_plan, RepairPatch body, blueprint body, physical table/field details, or result rows.
- Compile failure is fail-closed and does not call execute.

## Residual Risk

- PR1.3 provides the controlled DatasetAgent runtime contract and minimal orchestration. `/chat/stream` cutover, retry writer migration, and dual-path parity remain PR1.4 - PR1.5.
