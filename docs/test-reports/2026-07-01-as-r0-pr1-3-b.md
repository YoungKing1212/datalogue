## AgentScope 2.0 外部工具执行模型复验

- AgentScope 2.0 文档确认支持 `ToolBase(is_external_tool=True)`、`RequireExternalExecutionEvent`、`ExternalExecutionResultEvent` 和 `ToolResultBlock`，可以承载“Agent 提出下一步 tool call，宿主 Runtime 外部执行后回填结果”的模式。
- 文档中未发现可直接表达 Datalogue 业务安全状态机的 SDK 约束，包括固定工具顺序、敏感参数拦截、compile handle 绑定和 execute handle 校验；因此本阶段由 `DatasetAgentToolCallRuntime` 实现 Datalogue 侧 fail-closed 控制。
- 新增受控会话接口：
  - `DatasetAgentToolCallSession`：保存当前期望工具序号、compiled_query_ref、artifact_ref 和内部状态。
  - `DatasetAgentNextToolCall`：模拟 AgentScope external tool event 的 Datalogue 投影，Agent 只能提交 tool 名称和受限参数。
  - `handle_agent_tool_call()`：统一执行白名单、顺序、敏感参数和 handle 校验。
- Agent 可见 compile 响应只返回 `compiled_query_ref`，不返回 SQL；`execute_compiled_query` 只能接受当前会话中 compile 产生的 `compiled_query_ref`。

## 后端日志口径

- 新增 `app.services.agentscope_middlewares.DatasetRuntimeToolLoggingMiddleware`：
  - 继承 AgentScope 2.0 SDK 的 `ToolMiddlewareBase`。
  - 通过 `on_tool_call()` 拦截 `ToolBase.__call__()` 的工具调用链。
  - `DatasetAgentScopeExternalTool(ToolBase)` 默认挂载该 ToolMiddleware，工具层日志也集中在同一 middleware 包管理。
- 已移除 event-level Dataset Runtime 日志：
  - `[agentscope.dataset_runtime.require_external_execution]`
  - `[agentscope.dataset_runtime.external_execution_result]`
- 仅保留 AgentScope SDK ToolMiddleware 日志：
  - `[agentscope.dataset_tool.call]`
  - `[agentscope.dataset_tool.result]`
- 已移除 Datalogue Runtime 自身日志：
  - `[dataset_agent.runtime.start]`
  - `[dataset_agent.runtime.tool]`
  - `[dataset_agent.runtime.result]`
  - `[chat.stream.dataset_agent_runtime_start]`
  - `[chat.stream.dataset_agent_runtime_completed]`
- 日志只包含安全摘要：`reply_id`、`tool_call_id`、`dataset_id`、`conversation_id`、`trace_id`、`tool`、`state`、`status`、`code`、`artifact_ref`、`row_count`、`column_count`、`tool_count`、`has_compiled_query_ref`、`has_artifact_ref`、`has_error_summary` 等。
- 日志不写 SQL、schema、raw rows、物理字段、`query_plan` 主体、`RepairPatch` 主体或 blueprint 主体；主链日志不再用 LangGraph / DatasetSubAgent 口径描述当前 atomic runtime。
