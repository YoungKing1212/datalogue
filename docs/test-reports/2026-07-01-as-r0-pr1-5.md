# AS-R0 PR1.5 Test Report: 双路径灰度 parity

## Scope

- 正式计划项：PR1.5 双路径灰度。
- 目标：feature flag 下新 Shell runtime 与 legacy `_stream_chat_singleturn` 对齐同一 final payload、artifact refs、trace contract。
- 非目标：不默认开启新 runtime，不替换 DatasetAgent 主链，不收缩 legacy `/chat` transport。

## Implementation Summary

- 新增 runtime parity harness，分别在 `AS_R0_AGENTIC_RUNTIME_ENABLED=false/true` 下跑同一 `_stream_chat` 请求。
- 验证 Shell wrapper 不改写 legacy final payload。
- 验证 AgentScope assistant message 的 `artifact_ref`、`trace_ref` 写回在双路径下保持一致。
- 保持默认关闭行为：PR1.5 只证明灰度路径兼容，不改变生产默认路径。

## Evidence

新增验收测试后直接通过；原因是 PR1.1 已经把 runtime flag path 实现为 `DatalogueAgenticShell.run_turn()` 包裹 legacy stream delegate，PR1.5 本身只补正式 parity gate 和测试报告，不引入新的 runtime 行为。
