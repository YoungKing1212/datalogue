# AS-R0 P2.4 Test Report: optional business agent controlled enablement

## Scope

- 正式计划项：P2.4。
- 目标：ReportAgent、PythonAgent、AuditAgent 从 placeholder 进入受控启用契约；每个 Agent 独立白名单、独立验收。
- 非目标：不默认开启这些业务 Agent，不实现真实报告生成、Python 沙箱或审计执行逻辑，不改变 `/chat/stream` 默认主链。

## Implementation Summary

- `DatalogueAgenticShell` 新增 `enabled_optional_agents` 构造参数。
- 默认 registry 仍只启用 `bi_lead_agent`；ReportAgent、PythonAgent、AuditAgent 默认仍是 disabled placeholder。
- 显式启用时，每个 Agent 只获得自己的单一工具白名单：
  - `report_agent`: `create_report_from_artifact`
  - `python_agent`: `run_sandboxed_analysis_on_artifact`
  - `audit_agent`: `classify_query_failure`
- Runtime driver 对这些可选工具只注册对应 provider/method spec；未启用工具仍留在 disabled/admin-gated contract 中。
- 未知 optional agent 配置 fail-closed。

## Acceptance Mapping

- ReportAgent 默认 disabled；显式启用后只开放 `create_report_from_artifact`。
- PythonAgent 默认 disabled；显式启用后只开放 `run_sandboxed_analysis_on_artifact`。
- AuditAgent 默认 disabled；显式启用后只开放 `classify_query_failure`。
- 单个 Agent 启用不会连带启用其他 Agent 或其他 future tools。
- Context Projection 仍会移除 SQL/schema/raw rows/query_plan/RepairPatch/blueprint body 等禁区内容。

## Residual Risk

- P2.4 只完成受控启用契约，不交付真实业务执行器。真实 Report/Python/Audit Agent 的业务实现需要新的已批准计划拆分推进。
