### Sprint 1：7/14 – 7/25 ｜ P0 「UI 体验闭环 + 子智能体设计」

**一句话目标**：Chat 主路径完整承接 BI Tools 渲染与 Multi-Agent 可视化，子智能体保留机制设计落地。

| 交付项 | 说明 | 角色 | 人天 |
|--------|------|------|------|
| **BI Tools 渲染（Tool UI）** | Chat 消息中展示工具运行中/成功/失败/artifact refs/安全摘要/耗时；Streamdown 流式状态接续 | 前端 | 5 |
| **Multi-Agent 可视化初版** | nested messages 展示 Leader/Worker 协作过程；reasoning 摘要只含安全业务信息，raw thinking 仅 debug gate 下可见 | 前端 | 4 |
| **子智能体会话级保留机制设计** | 同一 session 内 BI Worker 不随单轮任务结束而删除；设计 session-scoped worker pool；分析 AgentScope 2.0.3 的 session 生命周期与 agent 绑定关系 | AI + 后端 | 4 |
| **上下文压缩技术方案** | 基于 DeerFlow 三层中间件参考，制定 Datalogue 多轮上下文压缩方案（摘要阈值、技能包留存、工具输出外部化）；评估 AgentScope 中间件钩子可行性 | AI 域 | 3 |
| **Workbench 去常驻化收尾** | 普通 `/chat` 不挂 WorkbenchPanel；artifact 详情/失败态/retry 入口迁到 Chat 内 | 前端 | 3 |

**验收标准**：Chat 中可见工具执行过程卡片 + artifact 结果卡 + 推理摘要；子智能体保留方案完成评审；Workbench 不再常驻。

### Sprint 2：7/28 – 8/08 ｜ P0 「主链加固 + 观测基线」

**一句话目标**：子智能体 session pool 落地，AgentScope 全链路可观测基线建立。

| 交付项 | 说明 | 角色 | 人天 |
|--------|------|------|------|
| **子智能体 session-scoped pooling 落地** | 同一会话 session 内复用 BI Worker agent_id；空闲 TTL 到期释放；避免频繁 AgentCreate → TeamDelete；降级方案：Redis 缓存 worker agent_id | 后端 + AI | 5 |
| **AgentScope 观测基线** | task_id/trace_id 贯穿 Leader session → BI Worker → 工具调用 → artifact → 最终 answer；覆盖四个关键节点：session 创建、AgentCreate、工具执行、artifact 写入 | 后端 | 4 |
| **BI Worker 失败类收敛** | 针对 FIELD_NOT_FOUND/FILTER_MISSING 建立回归用例；校验 field_refs 自动兜底误报率 | AI 域 | 3 |
| **Chat 页失败态 + retry 闭环** | 失败诊断卡片（safe diagnosis + recommended action）；retry 按钮触发重试，保留原 artifact refs | 前端 | 3 |

**验收标准**：同一会话连续 3 轮问数不产生新 AgentCreate；task_id 可在日志中追踪全链路；5 条代表性问题 FIELD_NOT_FOUND 误报率下降。
