# Datalogue Agent 上下文入口

用途：给 Codex、Claude Code 等 Agent 做任务路由，避免把项目记忆、长计划和大源码文件默认塞进上下文。

## 启动规则

1. 先读根目录 `AGENTS.md`。
2. 需要判断任务域时读本文档。
3. 代码探索优先用 `.codegraph/`，再考虑 `rg` 和直接读文件。
4. `.codex/project-memory.md` 只按关键词检索，不全文读取。
5. `docs/superpowers/` 长计划只在继续对应任务时读取。
6. 修改关键代码时同步补充中文关键行级注释，优先写在方法调用或关键操作同一行，重点解释业务边界、跨层状态、fallback 和异常降级。

## 当前主执行入口

- Chat UI、Workbench retry/action 和数据集试问统一从 `/api/agentic-shell/tasks/stream` 创建 `AgenticShellTask`。
- `/api/chat/stream` HTTP route 已从执行链路删除，不再转发、不再作为兼容执行入口。
- AgentScope Message/Event 与迁移期 `LegacyWorkflowTaskRunner` 是内部运行时事实；前端、Workbench 和审计查询只依赖 Datalogue Event Envelope。
- `_stream_chat` 仅作为内部 LegacyWorkflowAdapter/service helper 暂存，不是公开 HTTP 执行入口。

## 项目记忆检索

只在这些场景读取 `.codex/project-memory.md`：

- 回顾历史完成情况
- 查找历史验证命令或残留风险
- 确认某功能是否已经做过
- 完成任务后追加记录
- “最新详细记录”超过 10 条时，把较早记录压缩到历史区；历史压缩条目超过 10 条时，继续深度压缩为主题摘要。

推荐：

```bash
rg -n "关键词1|关键词2|文件名" .codex/project-memory.md
```

避免：

```bash
sed -n '1,9999p' .codex/project-memory.md
```
