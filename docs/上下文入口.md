# 数语（Datalogue）项目上下文入口

> 本文件是 Codex / Claude 等 AI Agent 的项目入口文档。

## 项目概述

数语是一个面向企业数据的 **AI 原生智能问数平台**。业务用户用自然语言提问，系统通过 Agent 驱动的数据查询链路，给出可追溯、可审计的回答。

## 核心架构（当前 AS-R0 / P0 收口口径）

```
用户 → POST /api/agent-team/tasks/stream (SSE)
  → AgentTeamTaskRuntime
    → AgentScopeServiceTaskRunner（HTTP 调用 AgentScope Service）
      → AgentScope Service (子应用 /agentscope)
        → Agent Team (Leader Agent + BI Worker Agent)
          → Datalogue BI Tools（dataset_query / SQL编译/执行）
```

**关键点：**
- 当前唯一产品主链是 **`POST /api/agent-team/tasks/stream → AgentScope Agent Team → BI Worker Tools`**，所有问数能力、Workbench 回放和 OpenViking 接入都以这条链路为准。
- **Leader Agent 是控制面**：负责任务规划、候选确认、Worker 创建和 TeamSay 协调；任何提速方案都不得绕过 Leader 直接把用户问题送到执行工具。
- **BI Worker Agent 是执行/诊断面**：只能通过 Datalogue 暴露的受控工具完成资产召回、QueryPlan 校验、执行、修复和 artifact 写入。
- AgentScope Service 作为 FastAPI 子应用挂载在 `/agentscope`；Datalogue 保留任务、会话投影、artifact、checkpoint、权限与审计真相源。
- 旧 LangGraph、direct-query、legacy payload 和 BI LeadAgent 目录只作为历史迁移层、兼容层或内部 fallback 说明，不再作为当前架构主语。
- repair 是一等可信闭环：失败必须进入 **Failure Classifier → Private Diagnosis → Repair Planner → User Confirmation → Retry Executor → Artifact Writer**，而不是把原始错误直接暴露给用户。

## 快速命令

```bash
# 本地开发
cd datalogue-api && uvicorn app.main:app --reload

# 前端
cd datalogue-web && pnpm dev

# Docker 部署
docker compose up -d

# 测试
cd datalogue-api && pytest
```
