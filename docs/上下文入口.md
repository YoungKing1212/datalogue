# Datalogue Agent 上下文入口

用途：给 Codex、Claude Code 等 Agent 做任务路由，避免把项目记忆、长计划和大源码文件默认塞进上下文。

## 启动规则

1. 先读根目录 `AGENTS.md`。
2. 需要判断任务域时读本文档。
3. 代码探索优先用 `.codegraph/`，再考虑 `rg` 和直接读文件。
4. `.codex/project-memory.md` 只按关键词检索，不全文读取。
5. `docs/superpowers/` 长计划只在继续对应任务时读取。

## 项目记忆检索

只在这些场景读取 `.codex/project-memory.md`：

- 回顾历史完成情况
- 查找历史验证命令或残留风险
- 确认某功能是否已经做过
- 完成任务后追加记录

推荐：

```bash
rg -n "关键词1|关键词2|文件名" .codex/project-memory.md
```

避免：

```bash
sed -n '1,9999p' .codex/project-memory.md
```

## 验证选择

- 后端：相关 pytest，必要时真实 `/api/chat/stream`
- 前端：`npm run lint`、`npm run build`，必要时真实页面
- 多轮：ConversationStore / `_thread.last_success_task`
- 可观测：SSE step、response metadata、Langfuse trace 或本地 trace index
- 数据集治理：真实接口和工作台页面
